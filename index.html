SearXNG setup guide

To use RaiaSpace with SearXNG JSON results, the connected SearXNG instance must allow JSON output. If JSON is disabled, the instance may return HTTP 403.

search: formats: - html - json

Your SearXNG instance must allow requests from this website through CORS. For local development, run RaiaSpace and SearXNG from compatible origins or configure the appropriate CORS policy.

Standard SearXNG search requests do not require an API key — RaiaSpace never asks for or stores one.

How your data is used

  • Search queries are sent to your configured SearXNG instance only when Live SearXNG mode is active.
  • Local Demo mode does not send queries to any server — all results are sample data generated on this device.
  • Files you select are not uploaded by this frontend. They stay in memory for preview only.
  • Search history and settings are stored locally in this browser only.
  • RaiaSpace does not provide account sync in this version.

RaiaSpace can't guarantee absolute anonymity, and doesn't know what your configured SearXNG instance itself logs or stores — that depends on its own configuration.
