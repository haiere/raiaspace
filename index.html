This page is served over HTTPS, but the SearXNG URL uses HTTP. Your browser may block mixed content. Use an HTTPS SearXNG instance or deploy this page over HTTP.

RaiaSpace connects to a SearXNG instance for live search results. To use it:

  1. Install SearXNG locally or use a public instance.
  2. Enable JSON output in settings.yml:
search: format: json
  1. Enter the base URL above (e.g. http://localhost:8080) and click Save.
  2. Toggle Live SearXNG to enable it.

All search queries are sent directly to your SearXNG instance. RaiaSpace does not proxy or log your searches.

Privacy & data policy

RaiaSpace is built with privacy as a first principle.

  • No search queries are sent to RaiaSpace servers.
  • All searches go directly to your configured SearXNG instance.
  • Search history and settings are stored locally in your browser.
  • No cookies, trackers, or analytics are used.
  • You can clear your local data at any time.

RaiaSpace is open source. You can review the code and run it yourself.
